# hello-word
Este repositório serve para praticar o GitHub Flow.

## Truques de texto
'#' -> Coloca em um titulo

'* *' -> Coloca em italico

'** **' -> Coloca em negrito

'-' -> Coloca em lista simples

## Como adiconar um lista de tarefas
Coloque "- [ ]".

Exemplo:
- [ ] Teste 1
- [ ] Teste 2
- [ ] 
Se quiser que a tarefa fique concluida, coloque um "X" dentro.

## Como adiconar uma imagem
Coloque em: <img alt="*Nome da imagem*" src="* O link aqui *"" width="*Altura*" align="*Aliamento*">

Exemplo:

<img alt="Cloudy morning" src="https://octodex.github.com/images/cloud.jpg" width="100" align="center">

## Como adiconar um link em um texto
Coloqueo texto dentre "[]" e o link entre "()", tudo junto.

Exemplo:
Converter uma imagem ou vídeo do modo escuro para o modo claro usando [ffmpeg](https://www.ffmpeg.org)

## Como adiconar um codigo
Coloque entre tres "`", com primeiro a linguagem do codigo e depois o codigo.

Exemplo:
```bash
ffmpeg -i input.mp4 -vf "negate,hue=h=180,eq=contrast=1.2:saturation=1.1" output.mp4
```
